Contributing to iki1uc/ATOM — short guide

1) Read the Code of Conduct and this file.
2) If you want to contribute, open an Issue titled: "Contribution Intent: <short title>" and answer:
   - Who are you? (handle is OK)
   - What change do you want to make?
   - Why is it useful? (one paragraph)
   - Do you have any conflicts of interest or paid/sponsored work on this?
   - Contact (email or handle, optional)

3) Maintainers will review your intent and may:
   - Ask clarifying questions,
   - Invite you to the Trusted‑Contributors team,
   - Ask you to open a draft PR once invited.

4) For code changes:
   - Create a branch in your fork,
   - Open a PR against dev/main,
   - Include tests & docs,
   - Expect at least 2 approvals from Core‑Developers.

5) Security / Secrets: never commit secrets; use the Quarantine policy in docs/ if you find sensitive data.

By contributing you agree to the repository license and to act in good faith.
